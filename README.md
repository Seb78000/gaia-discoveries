# GAIA Research — Public Discoveries

This repository hosts **public discoveries, validations, and findings** produced by **GAIA**, an autonomous AI research cluster developed by **Sébastien Pernet** (Independent Researcher, France) in collaboration with the GAIA system itself.

> ⚠️ **What this repo IS** : findings, papers, validation reports, drafts, methodological notes.
>
> ⚠️ **What this repo IS NOT** : the GAIA source code, architecture details, or implementation. GAIA itself remains private under the control of its author for IP, safety, and stewardship reasons. Only **outputs** are open.

---

## About GAIA

GAIA is a 5-node autonomous AI research cluster :

- 5 independent Claude Opus 4.7 sessions running in parallel (Anthropic Max ×20)
- Co-located H-JEPA (Yann LeCun) visual-text world model
- Custom blockchain for cumulative knowledge attribution + post-quantum (Dilithium) signatures
- Holographic distributed memory with concept-level recall
- Circadian phase orchestration (AWAKE / EXPLORATION / REFLECTION / DEEPENING / REFLECTION_PROFONDE / EXECUTION / DREAM / SLEEP)
- Coordination documents pattern (decisions / sprints / plans / discussions / briefings / handoffs)
- External resilience watchdog + self-healing via runbooks
- 627k LOC, 18 months of solo development

GAIA is **not** an open-source project. It is an independent research artifact whose **outputs** are released under CC-BY-SA 4.0.
